# Recovered GE enclosure review and bounded prototype plan

Reviewed 5 October 2026 against public Rev3C baseline commit `11826a7f6ba1ed19131ddba46e4d62b06196a8c6`. This is a source/export review; enclosure generation, slicing and physical tests were not performed. Recovered sources and exports remain unchanged.

**Recommendation:** use `GE-printed-case/enclosure.py` as the editable starting point for the existing tapered, common-base prototype, with a C3-specific lid first and retained C6-specific alternatives. Keep the older cassette package as historical styling/mechanism reference. Neither package is a qualified enclosure for the selected dual-input Rev3C carrier. Both are **build123d Python**, rather than CadQuery. The shared board datum aligns; the installed-height/contact calibration is the principal mechanical blocker.

All recovered Python files passed syntax parsing. Generation was not executed. The delivered STEP files are editable exchange solids; STL files are print meshes. Neither retains the Python parameter/history structure. Independently imported **15 printed-package and 18 older-package STEP/STL pairs** all have valid STEP geometry, positive mesh volumes and exactly two incident triangles per mesh edge. Maximum STEP/STL volume difference is **0.094%**. The two optional printed inlays are multiple glyph solids by design. These checks establish export integrity, without verifying moving mechanisms or physical fit.

Fresh check method: STEP import/validity/solid count/volume/bounds used installed **build123d 0.10.0 with cadquery-ocp 7.8.1.1.post1**. A separate standard-library binary STL parser checked exact `84 + 50 × facet_count` file size, calculated signed volume from triangle tetrahedra and counted undirected edges using exact float vertex tuples. Closed-edge incidence is not a general self-intersection/normal-consistency proof. `provenance-counts.json` contains the compact method/version/count receipt; `inspection-receipt.json` retains each export's results and all file hashes.

The printed archive has no `exports/summary.json`, although `validate_exports.py` requires it, and contains no render PNGs. Its five manifests reference 10–28 absent inputs each, including electronics/cutaway meshes and external supplier references; regeneration/preparation is needed before those render recipes are usable. The older archive includes ten actual renders and 18 delivered export pairs, while its historical validation record describes 51 generated pairs. The old exterior/C6 mechanism/indicator-guide PNGs were inspected as pixels: they show the earlier fixed exterior button locations, transfer paddles, return springs and lower lightpipe cradles, which do not represent the later integral-button lid. Do not use those images to approve the current printed mechanisms. Supplier assets should retain their recorded licensing/redistribution constraints.

## Bounded prototype sequence

1. **Freeze this candidate and measurement record.** Preserve the selected dual-input/automatic-priority carrier and four firmware profiles. Record actual C3 and C6 revision/SKU, header pins/spacer/mating depth, carrier top, both actuator tops, USB shell/plug and RF connector/cable envelopes. Retain separate C6 geometry even while C3 is first.
2. **Coupon gate without electronics.** Use delivered C3/C6 button coupons and snap pair in one defined unfilled PETG profile, plus a separate lightpipe/press-fit test. Inspect actual slice/orientation/bridges and measure clearance, return, permanent set, release and closure-height repeatability. The crop limits are not a full paired-button or full-case trial. Record the process and measured tolerances before changing only contact-reach/stop/fit parameters in a working copy.
3. **Calibrated C3 assembly gate.** With measured switch/stack bounds, establish released gap >0, worst-case electrical make before stop and stop within verified permitted travel/force. Fit actual fully seated assembly unpowered. Test each button and BOOT-held/RESET-pressed recovery, USB/J1 full access, optics, module restraint and lid-removal cable slack. No switch serves as a module retainer.
4. **Preserved C6 gate.** Repeat the same measurements/calibration on its own lid and actual conditional switch identity. Check U.FL/ceramic maximum envelope and final RF selection. C3 success is not evidence of C6 actuation or antenna clearance.
5. **Whole-case installation gate.** Independently check current component maximum envelopes, solder tails, cable/strain relief, repeated closure/actuation and loaded thermal behavior. Test optical/RF performance, vibration/tug and intended appliance-adjacent steel/orientation. Pick a service-cycle target before fatigue testing. Optional external bulkhead, remote lead and magnets each need their applicable retention/RF checks.

This closes source recovery and identifies a prototype path. It does not close printer fit, switch safety, lifetime, RF, thermal, ingress/flame or appliance qualification. No redesign, safety-circuit edit or manufacturing commitment is required to begin the measurement/coupon stage.
