# Enclosures

Enclosure files are grouped by the PCB family they were designed to fit.

[Back to the project overview](../README.md)

| Enclosure | Intended hardware | Status |
| --- | --- | --- |
| [Rev 3C enclosure](rev3c/README.md) | Rev 3C socketed XIAO carrier | Printable candidate with a raised USB-C window for the socketed module; physical fit and RF testing pending. |
| [Rev 3B enclosure](rev3b/README.md) | Rev 3B XIAO carrier | Printable candidate with antenna and magnet options; physical fit and RF testing pending. |
| [Rev 2 enclosure](rev2/README.md) | Rev 2.x board outline | Existing printable design; Rev 2.2 fit still requires a physical check. |

The editable CAD source, printable files, and documentation images are kept separately. The final check is printing the enclosure and test-fitting an assembled board.
