# Rev1 native source review

October 3, 2026, genuine KiCad 9.0.9. The cleaned historical source has **zero ERC errors, one retained ERC alias warning, zero DRC findings, zero unconnected items and zero schematic parity findings**. This is a source and export review; appliance compatibility, electrical protection and manufacturing release remain unqualified.

## Source and bounded changes

The exact restored source was public commit `87984047ee029efb83bf9947dc21818fd18e39b3`, recorded in [restoration provenance](../design/RESTORED-PROVENANCE.json). That record describes the original input bytes. The current edited source is independently bound by [preservation proof](native-kicad-9.0.9/preservation-proof.json) and [artifact manifest](native-kicad-9.0.9/manifest.json).

- The inherited 59 parity messages were 39 autogenerated net-name substitutions. The previously reviewed [net-name correction](../design/NET-NAME-CORRECTION.json) is retained. All 166 original electrical `(reference, pin)` memberships and every connected-pin group are unchanged.
- All 21 embedded symbol definitions are recovered into [LegacySymbols](../design/symbols/LegacySymbols.kicad_sym). Pin names, numbers, types and geometry are exact; only library namespaces changed. Three excluded PWR_FLAG symbols model the actual external VDC source, J1's external buck +5V output and shared return. They add no physical parts and establish no voltage/current guarantee. The classic development-board symbol already models +3V3 as its power output; that original definition is preserved.
- All 61 embedded footprints are recovered into a project-local library, rather than replaced with current stock geometry. [Footprint mapping](../design/footprints/source-map.json) retains original IDs. Native comparison proves all 61 positions/orientations, 174 native pad geometry/net/layer/drill records, and 377 track/via records unchanged. Two RJ45 NPTH pads explicitly spell their original F.Cu/B.Cu/F.Mask/B.Mask set to avoid native 9's wildcard expansion onto absent internal layers.
- Original conductor endpoints, junctions, labels, no-connects and symbol anchors are on a 25 mil (0.635 mm) grid: all 572 coordinates pass. Setting the missing project connection-grid metadata to 25 mil removes the inherited 226 off-grid warnings without moving any node. Every original project rule, severity, exclusion, class and assignment is retained.
- J2's two crossing silk endpoints are clipped from x136.98 to x134.8 mm inside the x135 mm board edge; two vertical silk segments wholly outside the board are removed. Copper, holes, courtyard, fab outline, connector placement and all printed text remain unchanged. This removes the two original silk-edge findings.

## Original architecture and open qualification

Rev1 uses a generic 38-pin classic ESP32 development-board interface, one RJ45 pin-1 supply input, F1/Q1/Q2 and an external buck-module J1. RJ45 pin 3 is unconnected. The generic symbols and original resistor/capacitor/TVS/zener/supervisor identities are preserved; no regulator or rating selection was introduced.

ESP UART assignments remain GEA2 TX GPIO18 / RX GPIO19, and GEA3 TX GPIO17 / RX GPIO16. Current C3 profiles do not apply. The separate classic-firmware work is outside this CAD change.

Original schematic notes such as the +9V to +16V input range, inrush protection and supervisor behavior are historical design claims, not measurements or qualification results. Source tolerances/current/transients, polarity and inrush behavior, TVS/zener/PMOS coordination, buck/module identity and startup, supervisor thresholds/timing, thermal behavior, physical fit and appliance/RF behavior remain open. Neither ERC flags nor a zero-error DRC grants manufacturing release or a supply envelope.
