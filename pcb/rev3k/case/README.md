# Rev 3K printed enclosure

Common friction-fit base with closed USB wall, chip-specific BOOT/RESET twin-leaf printed buttons, stops and three separate light pipes. Use the C3 lid for the C3 and the C6 lid for the C6. The PCB is **70 × 32 × 1.6 mm**. The nominal assembled case is **77.2 × 40.0 × 31.9 mm**, excluding the appliance cable. STEP and STL use millimetres and the assembled coordinate frame. The board underside is at z = 3.65 mm. Orient the parts in the slicer before test printing. Print the light pipes in translucent material. The roof retains their collar when inserted from the inside, subject to the dry-fit check.

The C3 antenna reservation places a 40 × 20 × 1.8 mm FPC upright in two edge supports. Its lead has a 2 mm diameter modeled corridor from the published module U.FL position, with a 5 mm planar bend and 31.1 mm centerline run. Confirm the supplied antenna feed location, available lead length, bend at the mated U.FL and strain relief on a real assembly. The C6 onboard ceramic antenna is checked against the separate lid using the module-derived package envelope. The native PCB retains the module's copper keepout. Radio performance requires a real appliance installation.

See case-checks.json for the module-specific switch centers, modeled case-to-board overlaps, intentional closure interference and C6 ceramic clearance. Stack height is assumed to be 11 mm. The case has a closed end at the USB receptacle. Unplug the appliance cable before opening the case for USB. Neither the plastic shell nor D11 provides galvanic isolation. Check plug latch clearance, fully seated module height, socket tail/solder clearance, LED alignment, button rest/travel without preload, closure force and material fatigue on physical prints. A bridged or open link is only for the documented circuit section. Leave both input protection paths intact.

The lids engrave the button names, module type and unplug-before-USB instruction on the fixed roof. JLC lists ±10% board thickness at 1.6 mm. A 1.76 mm board would leave only 0.04 mm nominal clearance to the printed retention sleeves before plastic tolerances, so test the thick-board fit and adjust the sleeve height if needed. [JLC board thickness tolerance](https://jlcpcb.com/capabilities/pcb-capabilities)

## Antenna clearance and print checks

The common base now leaves **0.35 mm** below the C3 antenna envelope. The previous base reached 0.9 mm into its lower edge. Use the revised base with either module lid. The lid rails have only 0.12 mm nominal clearance to the antenna. Test the printed pocket with the supplied antenna before snapping the case shut.
