# Geometry-based DC comparison

Run power-export.py with system KiCad pcbnew, the native board path and an output JSON path. Run power-model.py with that JSON and the results CSV path, using Python with Shapely 2.1.2, NetworkX 3.4.2, SciPy and NumPy. Run ground-mesh.py with system pcbnew, the board path, grid pitch (0.25 mm) and a new CSV path. The mesh script appends rows.

The rail model solves a conductance graph from the delivered track endpoints, lengths, widths, layer transitions and connected pad polygons. It combines branches in parallel. Connected overlapping copper is treated as equipotential at the contact. The ground model uses the actual four-layer fill and metal, samples on a 0.25 mm square grid and includes ground vias and connector grounds. Small features can be missed and the model snaps contacts to the grid. Models use 35 µm outer copper and compare 15.2 µm and 30.48 µm inner copper, 20 µm via-wall plating, 1.6 mm board, copper resistivity at room temperature. These are assumptions for comparing the two stacks. Request actual factory minimums, etch width and via plating. Resistance and voltage exclude connector contacts, parts, source wiring and the module. The 0.60 A and 1.01 A columns apply the indicated current separately to each path. They are sensitivity cases, not claims that every branch carries that current. The converter input and output currents differ. Heating, high-frequency return inductance, hot-plug, USB backfeed and transient startup need measurement.
